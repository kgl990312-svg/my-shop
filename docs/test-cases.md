- 작성일: 2026-11-17 (수정: 2026-11-23, TC-29~TC-33 추가)
- 배포 주소: https://kgl990312-svg.github.io/my-shop/

## 1. 테스트 케이스 표

### 1-1. 시작 전에 읽어 주세요

| 항목 | 내용 |
| --- | --- |
| 사이트 열기 | 크롬(Chrome) 브라우저 주소창에 배포 주소 `https://kgl990312-svg.github.io/my-shop/`를 입력한다. 처음 보이는 화면이 메인 화면이다. |
| 데스크탑 화면 | 브라우저 창을 가로 1280px 이상으로 크게 띄우고 마우스로 누른다. (노트북·모니터 전체 화면이면 된다) |
| 휴대폰 화면(390px) | 실제 휴대폰으로 배포 주소를 열거나, 크롬에서 아래 순서로 맞춘다.<br>1. 키보드 F12를 눌러 개발자 도구를 연다.<br>2. Ctrl + Shift + M을 눌러 기기 모드를 켠다.<br>3. 화면 위쪽 기기 선택 칸에서 "Dimensions: Responsive"를 고르고, 폭 칸에 390을 입력한다.<br>4. 같은 줄의 기기 종류를 "Mobile"로 바꿔 터치를 켠다.<br>5. F5로 새로고침한다. (새로고침해야 휴대폰 화면으로 바뀐다)<br>이 상태에서는 마우스 클릭이 손가락 탭으로 처리된다. |
| 다른 폭(375px, 768px) | 위 3번에서 폭 칸에 375 또는 768을 입력한 뒤 F5로 새로고침한다. |
| 크기(px) 재는 법 | 개발자 도구(F12)에서 Ctrl + Shift + C를 누르고, 잴 부분에 마우스를 올리면 "가로 × 세로" 크기가 표시된다. 세로 숫자가 높이다. |

| 결과 칸 | 테스트한 뒤 기대 결과와 모두 같으면 "통과", 하나라도 다르면 "실패"라고 적는다. |

### 1-2. 화면 이름과 찾아가는 법

| 화면 ID | 화면 이름 | 찾아가는 법 |
| --- | --- | --- |
| P01 | 메인 화면 | 배포 주소를 열면 나오는 첫 화면. 다른 화면에서는 맨 위 가운데 "MOA 모아" 로고를 누른다. |
| P02 | 상품 상세 화면 | 메인 화면의 "케이스 종류" 영역에서 케이스 카드(사진)를 누른다. |
| P03 | 꾸미기 화면 | 상품 상세 화면 맨 아래에 붙어 있는 "꾸미기 시작" 버튼을 누른다. |
| P04 | 확인 화면 | 꾸미기 화면 오른쪽 위 "완료" 버튼을 누른다. (스티커·큐빅·각인을 하나 이상 붙여야 눌린다) |
| P05 | 주문 정보 화면 | 확인 화면 맨 아래 "바로 구매하기"를 누르거나, 장바구니 화면 맨 아래 "주문하기"를 누른다. |
| P06 | 주문 완료 화면 | 주문 정보 화면에서 모든 칸을 채우고 "결제하기"를 누른다. |
| P07 | 장바구니 화면 | 화면 맨 위 오른쪽의 가방 모양 아이콘을 누른다. (꾸미기 화면에는 없음) |
| M01 | 나가기 안내창 | 꾸민 내용이 있을 때 나가려고 하면 뜨는 작은 창. "취소"·"나가기" 버튼이 있다. |
| M02 | 전체 초기화 확인창 | 꾸미기 화면 위쪽 "전체 초기화"를 누르면 뜨는 창. "취소"·"지우기" 버튼이 있다. |
| M03 | 이용약관 안내창 | 화면 맨 아래(푸터)의 "이용약관"을 누르면 뜨는 창. |
| M04 | 개인정보처리방침 안내창 | 화면 맨 아래(푸터)의 "개인정보처리방침"을 누르면 뜨는 창. |
| M05 | 종류 변경 안내창 | 꾸민 내용이 있을 때 꾸미기 화면에서 다른 케이스 종류를 고르면 뜨는 창. "취소"·"바꾸기" 버튼이 있다. |
| M06 | 도움말 안내창 | 꾸미기 화면 왼쪽 위 "?" 버튼을 누르면 뜨는 창. |
| M07 | 미리보기 창 | 확인 화면·주문 완료 화면에서 꾸민 케이스 사진을 누르면 어두운 배경 위에 크게 뜨는 창. |

### 1-3. 꾸미기 화면(P03) 버튼 위치

| 위치 | 버튼 |
| --- | --- |
| 맨 위 왼쪽 | "←"(뒤로), "?"(도움말) |
| 맨 위 오른쪽 | "되돌리기", "다시 실행", "전체 초기화", "완료" (휴대폰에서는 "전체 초기화"가 "⋯" 버튼 안에 있다) |
| 케이스가 놓인 영역의 왼쪽 위 | 배율 버튼 "−"(축소), "100%" 같은 배율 숫자, "+"(확대), "리셋" |
| 화면 오른쪽 세로 줄 | 위에서부터 "케이스 색", "큐빅", "스티커", "각인", 줄 아래쪽에 "케이스 종류". 누르면 화면 아래에 목록 패널이 열린다. |
| 붙인 스티커를 누르면 생기는 선택 상자 | 상자 안을 끌면 이동, 네 모서리의 작은 네모를 끌면 크기 조절, 상자 아래 동그라미를 끌면 회전, 오른쪽 위 바깥의 동그란 "X"를 누르면 삭제 |
