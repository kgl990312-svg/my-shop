# 인터랙션 목록

현재 구현(`src/`)에 있는 인터랙션을 모두 정리하고, 모바일에서 어떻게 처리할지 제안한다.

## 전제

- 처음에는 데스크탑 기준으로만 만들어져 있었다. 이후 터치 기기(휴대폰·태블릿)에서만 동작하는 규칙을 각 CSS 파일 끝의 터치 전용 블록에 추가했다(아래 "모바일 인터랙션 정리표"와 "수정 내역" 참고).
- 화면 배치 전체를 바꾸는 반응형 작업은 아직 하지 않았다. `PROJECT_CONTEXT.md`에는 "[미정], 6단계 반응형"으로 적혀 있다.
- 아래 "인터랙션 목록"의 **모바일 처리제안** 열은 처음 분석할 때의 제안이다. 실제로 정해서 적용한 방식은 "모바일 인터랙션 정리표"를 기준으로 본다.
- 표는 위치 순서(공통 → P01 → … → P07)로 정리했다. 66번부터는 분석 뒤에 새로 추가한 인터랙션이다.

## 모바일 인터랙션 정리표

지금까지 정한 모바일·태블릿(터치 기기) 처리 방식만 따로 모은 표다. 데스크탑의 화면과 동작은 바뀌지 않는다.
여기 없는 "유지" 항목은 터치 기기에서도 데스크탑과 똑같이 동작한다. 표는 번호 순서다.

- **모바일 판단 기준 (절대 규칙):** 폭 1024px 이하의 터치 기기(휴대폰·태블릿). CSS는 `@media (hover: none) and (pointer: coarse) and (max-width: 1024px)`, JS는 같은 조건의 `isMobile()`(`src/utils/device.js`). 데스크탑(1025px 이상)과 마우스 기기에서는 모바일 코드가 동작하지 않는다. 손가락 동작은 여기에 더해 `pointerType === 'touch'`일 때만 처리한다.
- **휴대폰/태블릿 구분:** 폭 768px 기준 (후기 개수, 케이스 종류 2×2 그리드)

**절대 규칙:** ① 데스크탑(1025px 이상)의 화면과 동작은 바뀌지 않는다 ② 모든 변경은 모바일 전용 코드를 덧붙이는 방식 ③ 커스텀 커서 등 마우스 전용 효과는 터치 기기에서 끈다 ④ 정리표대로 하고, 애매한 것은 고치지 않고 질문으로 남긴다.

- **1024px 조건:** 모든 모바일 전용 CSS 블록(23곳)과 JS 판단에 `max-width: 1024px`를 더했다. 이전에는 폭 1025px 이상인 아이패드 가로 모드에도 모바일 동작이 적용됐다. JS 판단은 `src/utils/device.js`의 `isMobile()` 하나로 모았다.
- **CSS를 "원본 + 덧붙임"으로 다시 만듦:** hover 효과를 끄려고 기존 `:hover` 규칙을 `@media (hover: hover)` 안으로 옮겼던 것을 원래대로 되돌렸다. 대신 모바일 전용 블록에서 hover 상태를 원래 값으로 덮는다. CSS 6개 파일 모두 원래 줄은 하나도 바뀌지 않았다(파일 끝에 덧붙인 코드만 있음).
- **JS에서 고쳤던 기존 줄을 덧붙이는 방식으로 바꿈:**
  - 29 되돌리기·다시 실행 글자 숨김: 글자를 `<span>`으로 감쌌던 것을 되돌리고, CSS로 모바일에서 글자 크기를 0으로 만든다(화면 낭독기는 그대로 읽음).
  - 30 전체 초기화 숨김: 버튼에 붙였던 클래스를 되돌리고, CSS의 순서 선택자(3번째 버튼)로 숨긴다.
  - 32·33 두 손가락: 캔버스에 붙였던 `ref`와 배율 영역 클래스를 되돌리고, 기존 `caseRef`에서 요소를 찾아 감지 코드와 `is-pinching` 클래스를 붙인다.
  - 36 패널 전환: 패널의 `className`과 각인 패널 여는 조건을 원래대로 되돌리고, 별도 효과에서 `is-switch`를 붙인다(화면에 보이기 전에 붙음).
  - 43 안내 문구: "드래그해주세요"를 그대로 두고 모바일용 문구 `<span>`을 덧붙여, CSS로 모바일에서만 바꿔 보인다.
  - 20 후기 숨김: 데스크탑 4개씩 숨기는 기존 줄을 되돌리고, 모바일에서만 그린 뒤 숨김 속성을 푼다.
  - 52 미리보기 크기: 기존 크기 계산 줄을 되돌리고, 모바일에서만 그린 뒤 틀을 키우고 케이스를 같은 비율로 확대한다.
  - `CompletePage.jsx`의 import 줄도 되돌리고 새 import 줄을 따로 더했다.
