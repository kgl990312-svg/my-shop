# 인터랙션 목록

현재 구현(`src/`)에 있는 인터랙션을 모두 정리하고, 모바일에서 어떻게 처리할지 제안한다.

## 전제

- 처음에는 데스크탑 기준으로만 만들어져 있었다. 이후 모바일(폭 1024px 이하 터치 기기: 휴대폰·태블릿)에서만 동작하는 규칙을 각 CSS 파일 끝의 터치 전용 블록에 추가했다(아래 "모바일 인터랙션 정리표"와 "수정 내역" 참고).
- 화면 배치를 바꾸는 반응형 작업(6단계)은 휴대폰·태블릿 전 페이지에 적용했다. 기준은 `PROJECT_CONTEXT.md` 7번.
- 아래 "인터랙션 목록"의 **모바일 처리제안** 열은 처음 분석할 때의 제안이다. 실제로 정해서 적용한 방식은 "모바일 인터랙션 정리표"를 기준으로 본다.
- 표는 위치 순서(공통 → P01 → … → P07)로 정리했다. 66번부터는 분석 뒤에 새로 추가한 인터랙션이다(71~73은 2026-11-16·17에 추가).
- 수정 내역의 TC 번호는 그 날짜의 번호다. 2026-11-24에 테스트 케이스를 정리하며 번호를 다시 매겼다(옛 TC-25~32 → TC-24~31, 옛 TC-35~38 → TC-32~35, 옛 TC-24·33은 뺌, 옛 TC-34는 TC-10에 합침). 지금 번호는 `docs/test-cases.md`를 본다.

## 모바일 인터랙션 정리표

지금까지 정한 모바일(폭 1024px 이하 터치 기기: 휴대폰·태블릿) 처리 방식만 따로 모은 표다. 데스크탑(1025px 이상)의 화면과 동작은 바뀌지 않는다. 이 규칙은 레이아웃 기준이라, 문구 같은 내용 변경과 아래 "데스크탑도 함께 바뀐 것"의 승인된 예외는 데스크탑에도 적용된다.
여기 없는 "유지" 항목은 모바일에서도 데스크탑과 똑같이 동작한다. 표는 번호 순서다.

- **모바일 판단 기준 (절대 규칙):** 폭 1024px 이하의 터치 기기(휴대폰·태블릿). CSS는 `@media (hover: none) and (pointer: coarse) and (max-width: 1024px)`, JS는 같은 조건의 `isMobile()`(`src/utils/device.js`). 데스크탑(1025px 이상)과 마우스 기기에서는 모바일 코드가 동작하지 않는다. 손가락 동작은 여기에 더해 `pointerType === 'touch'`일 때만 처리한다.
- **휴대폰/태블릿 구분:** 폭 768px 기준 (후기 개수, 케이스 종류 2×2 그리드)
