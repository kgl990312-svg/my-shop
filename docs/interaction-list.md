# 인터랙션 목록

현재 구현(`src/`)에 있는 인터랙션을 모두 정리하고, 모바일에서 어떻게 처리할지 제안한다.

## 전제

- 지금은 데스크탑 기준으로 만들어져 있고, 반응형 `@media` 규칙은 없다(`prefers-reduced-motion`만 있음).
- 모바일 대응은 `PROJECT_CONTEXT.md`에 "[미정], 6단계 반응형"으로 적혀 있다.
- 아래 제안은 터치 화면과 좁은 폭을 기준으로 했다.
- 표는 위치 순서(공통 → P01 → … → P07)로 정리했다.

**적용 방법**

- **hover 효과:** 모든 `:hover` 규칙을 `@media (hover: hover)` 안으로 옮겼다. 키보드로 고를 때 나오는 효과(`:focus-visible`, `:focus-within`)는 밖에 그대로 둬서 접근성은 바뀌지 않는다.
- **끌어다 놓기:** 스티커 칸을 누를 때 입력 종류(`pointerType`)가 `touch`이면 탭 전용 흐름으로 처리한다. 6px 넘게 움직이거나 브라우저가 스크롤을 시작해 `pointercancel`이 오면 붙이지 않는다. 마우스와 펜은 기존 끌어다 놓기를 그대로 쓴다.
- **스티커 목록 넘기기:** `@media (pointer: coarse)`일 때 스티커 칸을 `touch-action: pan-x`로 바꿔, 칸 위에서도 목록을 옆으로 넘길 수 있게 했다. 모바일 주의사항 2번이 이걸로 해결된다.
- **안내 문구:** 터치 기기에서는 "눌러서 붙여요"를 보여준다. (이후 "눌러서 붙이고, 끌어서 옮겨요"로 바꿈, 아래 수정 내역 참고)
- **모바일 스티커 흐름 (확정):** 패널에서 탭해서 가운데에 붙이고(39), 붙은 스티커를 터치한 채로 끌어 원하는 곳으로 옮긴다(44). 패널에서 캔버스로 바로 끌어오는 방식은 쓰지 않는다.

**한계**

- **터치스크린 노트북:** 마우스가 주 입력인 터치스크린 노트북에서는 손가락 탭으로 붙이는 건 되지만, 스티커 칸 위에서 목록을 밀어 넘기는 건 안 된다.
