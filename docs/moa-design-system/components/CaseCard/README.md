# CaseCard

P01 메인의 케이스 종류 카드로, 누르면 그 종류의 P02 상품 상세로 가는 핵심 행동이에요.

- 흰 카드, 2px `line-accent` 테두리, `radius-lg`(20px), `shadow-card`. 핵심 행동이라 다른 카드보다 테두리가 굵어요.
- 내용: 정사각 이미지(`radius-md`) → 이름(크기) 18px 700 → 가격 18px 800 `accent`. 할인율·찜은 없어요.
- 가로로 나란히, 사이 24px (4개: 원형·둥근 정사각형·하트·꽃). 휴대폰에서는 2×2.
- 휴대폰·태블릿(터치 기기)에서는 호버 효과 없이 꾸미지 않은 케이스만 보여 줘요.
- 호버: 꾸미지 않은 케이스 이미지 위로 꾸민 예시 이미지가 0.3초 동안 서서히 나타나요. 왼쪽 위에 "꾸민 예시" 표시. 그림자도 조금 진해져요(0 10px 28px rgba(196, 81, 63, 0.16)). 키보드 선택 때도 같아요.
- 이미지: 종류마다 꾸미지 않은 케이스 1장(`src/assets/site/card`) + 꾸민 예시 1장(`src/assets/site/hover`).
