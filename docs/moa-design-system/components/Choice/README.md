# Choice

여러 개 중 하나를 고르는 선택 상자와 동의 체크박스예요.

- 선택 상자: 높이 64px, 모서리 16px, 같은 너비로 나란히(사이 12px). 고른 것은 2px `accent` 테두리 + `bg-soft` 배경 + 700, 나머지는 1.5px `line-strong` + 흰 배경 + 600.
- 쓰는 곳: P05 결제 수단(카드 / 간편결제 / 무통장 입금). 가상 사이트라 실제 결제창은 없어요.
- 같은 규칙을 P03 도구 버튼(고른 버튼 `bg-soft`)과 케이스 종류 패널(지금 종류 `bg-soft`)에도 써요.
- 체크박스: 22px, 체크 색 `accent`, 글자 15px. 필수 동의는 `accent` 별표.
