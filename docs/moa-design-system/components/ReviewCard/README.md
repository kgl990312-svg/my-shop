# ReviewCard

P01 메인 "직접 꾸민 후기"의 카드로, 완성 케이스 사진과 짧은 후기를 보여 줘요.

- 흰 카드, 1px `line`, `radius-lg`. 사진(정사각) → 별점 5개(`deco-coral`) → 작성자(가운데 가림)·날짜 13px → 한 줄 후기 15px → 케이스 종류 태그.
- 후기 문구는 한 줄까지만 보이고 넘치면 "…"으로 줄여요.
- 호버(키보드 선택 포함): 사진이 1.05배 확대(0.3초)되고, 한 줄 후기가 오른쪽에서 왼쪽으로 흘러 끝까지 보여 줘요. 처음 잠깐 멈춤 → 끝까지 흐름 → 잠깐 멈춤 → 처음부터 반복. 마우스를 떼면 원래대로, 카드 크기는 그대로.
- 8개를 한 화면에 4개씩 가로로 넘겨 봐요 (이전·다음 아이콘 버튼). 평균 별점, 후기 수, 더보기는 없어요.
- 예시 후기에는 사진 왼쪽 위에 "예시 후기" 표시를 붙여요.
