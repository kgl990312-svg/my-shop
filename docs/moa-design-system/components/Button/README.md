# Button

모든 버튼은 알약 모양(`radius-pill`)이고, 하는 일을 그대로 적은 이름을 써요.

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| 핵심 (primary) | `accent` 배경, 흰 글자 18px 700, 높이 56~60px, `shadow-cta` | 꾸미기 시작, 완료(44px), 바로 구매하기, 결제하기, 주문하기, 안내창의 나가기·지우기·바꾸기 |
| 테두리 (outline) | 흰 배경, 1.5px `accent` 테두리와 글자 | 장바구니 담기, 이미지 저장하기 |
| 연한 면 (soft) | `bg-soft` 배경, `ink` 글자 | 안내창의 취소 |
| 진한 (dark) | `ink` 배경, 흰 글자 | 약관·도움말 안내창의 닫기 |
| 작은 (small) | 흰 배경, 1px `line-strong`, 14px 600, 높이 44px | P03 상단 바 (되돌리기, 다시 실행, 전체 초기화) |
| 아이콘 | 48×48 원, 1.5px `line-strong` | 후기 이전·다음 |

- 한 화면에 핵심 버튼은 하나만 둬요 (P04는 바로 구매하기만 핵심, 장바구니 담기는 테두리).
- 안내창 두 버튼은 같은 너비로 나란히: 왼쪽 취소(soft), 오른쪽 실행(primary).
- 비활성 모양: 흐리게(투명도 40%), 그림자 없음. 비활성 규칙: 완료는 스티커·큐빅·각인이 없을 때, 결제하기는 필수 항목이 비었을 때.
- 호버: 핵심 버튼은 진한 코랄 `accent-hover`(#B04634), 테두리 버튼은 `bg-soft` 배경 + 글자·테두리 `accent-hover`(명도 대비 4.6:1, 2026-11-24), 작은·아이콘 버튼은 `bg-soft` 배경, 취소는 `bg-soft-strong`, 닫기는 #2C211C. 0.3초.
- 눌림: 0.98배로 살짝 작아져요. 비활성 버튼은 호버·눌림 때 바뀌지 않아요.
