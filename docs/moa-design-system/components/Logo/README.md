# Logo

모아의 글자 로고로, "MOA" 아래 줄에 "모아"를 두는 두 줄 형태예요.

- "MOA": 800, 자간 0.12em, `accent`. "모아": 600, `ink-muted`. 두 줄 모두 가운데 정렬, 줄 간격 1.15.
- 네비게이션 바: 30px / 14px, 바 가운데. 누르면 P01 메인 (P04·P05에서 꾸민 내용이 있으면 M01 나가기 안내창).
- 푸터: 20px / 11px, 회사 정보 위.
- 로고 이미지가 정해지면(4단계) 이 글자 로고를 바꿔요. 그 전까지 다른 곳에 새 로고 모양을 만들지 않아요.
