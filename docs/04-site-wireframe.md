## 표시 방법 (범례)

- 텍스트: 회색 선
- 이미지: X 상자
- 버튼·탭·입력창·선택 상자·체크박스·색 선택: 얇은 테두리
- 핵심 행동: 굵은 테두리 (P01-B01~B04 케이스 종류 카드, P02-B04 꾸미기 시작, P03-B06 완료, P04-B01 바로 구매하기, P05-B01 결제하기, P07-B01 주문하기)
- ID 규칙: GNB-네비게이션 / FTR-푸터 링크 / P-페이지 / M-안내창 / S-섹션 / B-버튼

## 배치

- 위 행 (주요 동선): P01 메인 → P02 상품 상세 → P03 꾸미기 → P04 확인 → P05 주문 정보 → P06 주문 완료
- 아래 행 (주요 동선 외): M01 나가기 안내창, M02 전체 초기화 확인창, M03 이용약관 안내창, M04 개인정보처리방침 안내창, M05 종류 변경 안내창, M06 도움말 안내창, M07 미리보기 창, 버튼-목적지 연결 표, P07 장바구니
- 섹션은 각 화면 안에서 위에서 아래로 쌓는다.

## 공통 요소

- 네비게이션 바 (각 화면의 S01, 꾸미기는 상단 바)
  - GNB-01 로고: P01·P02·P04·P05·P06·P07 네비게이션 바 가운데에 둔다. P01 메인 (P04·P05에서 꾸민 내용이 있으면 M01) · 홈 버튼은 따로 두지 않는다.
  - GNB-02 ← 뒤로: P02·P04·P05·P07 왼쪽에 둔다. 이전 페이지 (P02→P01, P04→P03 꾸민 상태 유지, P05→P04 또는 P07, P07→이전 페이지)
  - GNB-03 장바구니: P01·P02·P04·P05·P06·P07 오른쪽에 둔다. P07 장바구니 (P04·P05에서 꾸민 내용이 있으면 M01) · 숫자 = 담긴 개수 배지 (비어 있으면 숨김)
  - GNB-04 메뉴 "홈 · CASE · REVIEW": P01·P06 왼쪽에 둔다 (데스크탑은 글자 메뉴, 휴대폰은 햄버거 안). P01에서는 그 섹션으로 스크롤, P06에서는 P01로 가서 그 섹션에서 시작 · 주문 과정(P04·P05)에는 두지 않는다 (나중에 추가, `docs/interaction-list.md` 수정 내역)
  - 확인·장바구니·주문 정보는 네비게이션 바 아래에 페이지 제목 섹션(회색 선)을 둔다. 주문 완료에는 뒤로가 없고, 브라우저 뒤로가기를 누르면 메인으로 이동한다. (다시 결제 방지)
- 푸터 (꾸미기를 뺀 각 화면의 마지막 섹션)
  - 회사 정보 (회색 선): 회사명, 대표자, 사업자등록번호, 주소
  - 고객센터 (회색 선): 전화번호, 운영 시간
  - FTR-01 이용약관 (버튼): M03 이용약관 안내창
  - FTR-02 개인정보처리방침 (버튼): M04 개인정보처리방침 안내창

## 페이지별 구성

### P01 메인

- P01-S01 네비게이션 바
  - GNB-04 메뉴 (왼쪽): 홈 · CASE · REVIEW → 그 섹션으로 스크롤
  - GNB-01 로고 (버튼, 가운데): P01 메인 (맨 위로)
  - GNB-03 장바구니 (버튼, 오른쪽): P07 장바구니 (담긴 개수 배지)
- P01-S02 소개 배너 (한 배너 안에 문구와 이미지)
  - 소개 문구 (회색 선): 나만의 쿠션 케이스, 모아에서 완성해요
  - 예시 상품 이미지 (X 상자): 블러시 핑크 원형 케이스에 큐빅·리본·각인 "Moa"로 꾸민 예시 · 사진이 나타난 뒤 하얀 빛줄기가 대각선으로 한 번 지나감
- P01-S03 케이스 종류 카드 (가로 배치, 핵심 행동)
  - P01-B01~B04 케이스 종류 카드: P02 상품 상세 (고른 케이스 종류)
  - 카드 = 목업 이미지(X 상자) + 이름(크기)(회색 선) + 가격(회색 선)
  - 종류 4개: 원형, 둥근 정사각형, 하트, 꽃 (안쪽 홈은 모두 둥근 원형) · 가격: 원형 19,000 · 둥근 정사각형 20,000 · 하트 21,000 · 꽃 22,000원 · 할인율·찜 없음
  - 카드 이미지는 꾸미지 않은 흰 케이스, 마우스를 올리면 꾸민 예시 이미지로 바뀜
- P01-S04 직접 꾸민 후기
  - 섹션 제목 + 짧은 부제 (회색 선, 예: "직접 꾸민 후기" / "나만의 케이스를 자랑해 보세요") · 평균 별점·후기 수 없음 · 더보기 없음
  - 후기 카드 8개를 가로로 넘겨 보기 (한 화면에 4개, 휴대폰은 손가락으로)
    - P01-B05 이전 ← (버튼): P01 안에서 후기 카드 넘기기
    - P01-B06 다음 → (버튼): P01 안에서 후기 카드 넘기기
  - 후기 카드 = 완성 케이스 사진(X 상자) + 별점(별 5개) + 작성자(가운데 가림)·날짜(회색 선) + 한 줄 후기(회색 선, 한 줄, 마우스를 올리면 옆으로 흐름) + 케이스 종류(회색 선)
  - 카드를 누르면 후기 안내창: 사진·별점·전체 문구·케이스 종류를 크게 보여줌, ←/→ 버튼과 키보드로 다른 후기로 넘김
  - 예시 후기 (디자인 단계에서 "예시 후기"로 표시)
- P01-S05 푸터 (공통 요소)

### P02 상품 상세

- P02-S01 네비게이션 바
  - GNB-02 ← 뒤로 (버튼, 왼쪽): P01 메인
  - GNB-01 로고 (버튼, 가운데): P01 메인
  - GNB-03 장바구니 (버튼, 오른쪽): P07 장바구니 (담긴 개수 배지)
- P02-S02 상품 요약
  - 큰 목업 이미지 (X 상자)
  - 회색 선: 케이스 종류 이름, 크기, 가격
  - 짧은 설명 (회색 선): 소재, "꾸민 디자인은 케이스에 인쇄되고, 큐빅은 실제로 붙여 드려요"
- P02-S03 제작 안내
  - 단계 5개를 가로로 (아이콘 X 상자 + 짧은 이름 회색 선): 1. 케이스 색 고르기 → 2. 스티커·큐빅·각인으로 꾸미기 → 3. 확인하고 주문하기 → 4. 인쇄·각인하고 큐빅 붙이기 → 5. 배송
  - 기간은 쓰지 않음 (제작·배송 기간은 배송·교환 안내 참고) · 아이콘은 코랄 선 아이콘 5개 (팔레트, 스티커, 체크리스트, 프린터, 선물)
- P02-S04 탭 (지금 보고 있는 탭은 연회색)
  - P02-B01 상품정보 / P02-B02 사이즈 / P02-B03 배송·교환 안내 (버튼): 누르면 그 내용으로 스크롤해 이동
- P02-S05 상품정보
  - 상세 이미지 (X 상자, 종류마다 케이스를 열고 닫은 모습 1장, 사진 원래 비율), 상품 설명 (회색 선): 공통 문단 + 종류별 한 줄 (문구는 `PROJECT_CONTEXT.md` 6번)
- P02-S06 사이즈
  - 정보 상자 (회색 선): 크기, 호환 규격 안내(내 쿠션에 맞는 종류를 확인하는 방법) (쿠션 팩트 평균값으로 확정, `PROJECT_CONTEXT.md` 6번)
- P02-S07 배송·교환 안내
  - 정보 상자 (회색 선): 제작·배송 기간, 배송비, 주문 제작 상품 교환·환불 안내, 유의사항(큐빅) (문구는 `src/data/catalog.js`의 `SHIPPING_INFO`, `CUBIC_NOTICE`)
- P02-S08 하단 고정 바
  - P02-B04 꾸미기 시작 (버튼, 핵심 행동): P03 꾸미기 · 화면 아래에 고정
- P02-S09 푸터 (공통 요소)

  - 큐빅 · 스티커 패널 (공통 형태): 목록 (X 상자, 패널마다 8개, 배경이 투명한 스티커 이미지). 큐빅은 실제 아크릴 큐빅을 붙이고, 스티커는 인쇄, 클릭하면 케이스 가운데에, 끌어서 안쪽 점선 안에 놓으면 놓은 자리에 붙고 선택 상태 (점선 밖에 놓으면 붙지 않음), 모든 종류·색 공통, 스티커·큐빅 5개까지 추가 요금 없음·6개째부터 1개당 +500원 (각인은 1개당 +1,500원(최대 10글자)), 패널 제목 옆에 개수와 추가 요금 표시
  - 각인 패널
    - 각인 스타일 목록: 글꼴 2개(세리프, 모던) × 각인 색 3개(샴페인 골드, 로즈 골드, 실버) = 6가지. 칸 안에 예시 문구 "각인"(회색 선), 칸 아래에 스타일 이름(회색 선). 글꼴은 세리프(Cormorant Garamond + 고운바탕)·모던(Pretendard)으로 확정
    - 입력창: 스타일을 클릭하면 케이스 가운데에 "각인 입력" 표시(선택 상태) + 입력창 나타남 · 입력하면 실시간 반영 (붙이기 버튼 없음) · 10자 이내, 글자 수 0/10 · 빈 채로 선택을 풀면 사라짐 · 넣은 각인을 클릭하면 다시 수정
  - 케이스 종류 패널: 종류 목록 (X 상자 + 이름(크기)·가격 회색 선), 지금 종류는 연회색, 꾸민 내용이 있을 때 다른 종류를 고르면 M05 종류 변경 안내창
