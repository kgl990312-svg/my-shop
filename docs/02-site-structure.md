# 모아(MOA) 사이트 구성

## 기준

- 데스크탑 기준
- 이 문서에는 확정한 내용과 추후 결정으로 남긴 내용만 적는다.

## 1. 확정한 내용

### 전체 흐름

메인(케이스 종류 선택) → 상품 상세 → 꾸미기 → 확인 → 주문 정보 → 주문 완료

- 확인에서 "장바구니 담기"를 누르면 장바구니로 가고, 장바구니에서 "주문하기"를 누르면 주문 정보로 간다. (여러 개 구매)
- 확인에서 "바로 구매하기"를 누르면 장바구니를 거치지 않고 주문 정보로 간다. (하나 구매)
- 로그인 없이 주문한다. 계정 기능은 없다.

### 공통

- 네비게이션 바는 단순하게 둔다. 페이지별 구성은 아래 표와 같다.

| 페이지 | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| 메인 | | 로고 | 장바구니 |
| 상품 상세 | ← 뒤로 (메인) | 로고 | 장바구니 |
| 꾸미기 | ← 뒤로 (상품 상세), ? 도움말 | 되돌리기 · 다시 실행 · 전체 초기화 | 완료 |
| 확인 | ← 뒤로 (꾸미기, 꾸민 상태 유지) | 로고 | 장바구니 |
| 장바구니 | ← 뒤로 (이전 페이지) | 로고 | 장바구니 |
| 주문 정보 | ← 뒤로 (확인 또는 장바구니, 온 곳) | 로고 | 장바구니 |
| 주문 완료 | (없음) | 로고 | 장바구니 |

- 로고는 꾸미기를 뺀 모든 페이지의 가운데에 둔다. 로고를 누르면 메인으로 이동한다. (홈 버튼은 따로 두지 않는다.)
- 장바구니 버튼은 꾸미기를 뺀 모든 페이지의 오른쪽에 둔다. 담긴 개수를 숫자 배지로 보여주고, 비어 있으면 배지를 숨긴다.
- 확인·장바구니·주문 정보는 네비게이션 바 바로 아래에 페이지 제목("확인", "장바구니", "주문 정보")을 크게 둔다. 주문 완료는 완료 문구가 제목 역할을 한다.
- 주문 완료에는 뒤로를 두지 않는다. (결제가 끝난 뒤 다시 결제하는 실수를 막기 위함)
- 나가기 안내창: 꾸민 내용이 있는 상태에서 꾸미기의 ← 뒤로, 확인·주문 정보의 로고나 장바구니를 누르면 "꾸민 내용이 사라져요" 안내창을 띄운다. 버튼은 취소 / 나가기이고, 나가면 저장된 내용을 지운다.
- 미리보기 창: 확인과 주문 완료에서 꾸민 케이스 이미지를 누르면 어두운 배경 위에 이미지를 크게 보여준다. 오른쪽 위 X 또는 바깥을 클릭하면 닫힌다.
- 브라우저 뒤로가기는 화면의 ← 뒤로와 똑같이 처리한다. 주문 완료에서 브라우저 뒤로가기를 누르면 메인으로 이동한다. (다시 결제 방지)
- 자동 저장: 꾸미기, 확인, 주문 정보 화면에서 새로고침해도 꾸민 상태(케이스 종류, 케이스 색, 스티커·큐빅·각인)가 유지된다. 나가기 안내창에서 나가거나 주문을 완료하면 저장된 내용을 지운다.
- 장바구니 저장: 담은 케이스는 브라우저에 저장되어 새로고침하거나 다시 방문해도 남아 있다. 주문을 완료하면 주문한 케이스를 장바구니에서 지운다.
- 푸터: 꾸미기를 뺀 모든 화면 맨 아래에 둔다.
  - 회사 정보: 회사명, 대표자, 사업자등록번호, 주소
  - 고객센터: 전화번호, 운영 시간
  - 이용약관 링크: 누르면 이용약관 안내창을 띄운다.
  - 개인정보처리방침 링크: 누르면 개인정보처리방침 안내창을 띄운다.

### 메인

- 메인 화면 소개 문구: 나만의 쿠션 케이스, 모아에서 완성해요
- 구성: 소개 배너(소개 문구와 예시 상품 이미지를 한 배너로) 아래로 스크롤하면 케이스 종류 카드가 나온다.
- 케이스 종류 카드: 카드 안에 목업 이미지, 이름(크기), 가격을 위에서 아래 순서로 넣는다. 카드를 가로로 나란히 놓는다. 종류는 원형, 둥근 정사각형, 하트, 꽃 4개다. 마우스를 올리면 꾸민 예시 이미지로 바뀐다.
- 카드를 클릭하면 그 케이스 종류의 상품 상세로 이동한다.
- 할인율과 찜(하트) 버튼은 넣지 않는다.
- 직접 꾸민 후기: 케이스 종류 카드 아래, 푸터 위에 둔다.
  - 섹션 제목과 짧은 부제를 둔다. (예: "직접 꾸민 후기" / "나만의 케이스를 자랑해 보세요")
  - 후기 카드 8개를 가로 한 줄로 놓고, 이전(←) / 다음(→) 버튼으로 넘겨 본다. (한 화면에 4개)
  - 후기 카드: 완성 케이스 사진, 별점(별 5개), 작성자(가운데 글자 가림)와 날짜, 한 줄 후기(한 줄, 넘치면 …, 마우스를 올리면 옆으로 흐르며 끝까지 보임), 케이스 종류를 위에서 아래 순서로 넣는다.
  - 평균 별점과 후기 수, "더보기"는 넣지 않는다.
  - 가상 사이트라 후기는 예시로 채우고, 디자인 단계에서 "예시 후기"로 표시한다.

### 상품 상세

- 상품 요약: 큰 목업 이미지, 케이스 종류 이름, 크기, 가격, 짧은 설명(소재, "꾸민 디자인은 케이스에 인쇄되고, 큐빅은 실제로 붙여 드려요")
- 제작 안내: 상품 요약 바로 아래, 탭 위에 둔다. 단계 5개(케이스 색 고르기 → 스티커·큐빅·각인으로 꾸미기 → 확인하고 주문하기 → 인쇄·각인하고 큐빅 붙이기 → 배송)를 아이콘과 짧은 이름으로 가로로 보여준다. 기간은 쓰지 않고, 제작·배송 기간은 배송·교환 안내에서 보여준다.
- 탭 3개: 상품정보, 사이즈, 배송·교환 안내. 탭을 누르면 그 내용으로 스크롤해 이동한다.
  - 상품정보: 상세 이미지와 상품 설명
  - 사이즈: 크기와 호환 규격 안내(내 쿠션에 맞는 종류를 확인하는 방법)
  - 배송·교환 안내: 제작·배송 기간, 주문 제작 상품 교환·환불 안내
- 화면 아래에 "꾸미기 시작" 버튼을 고정한다. 누르면 그 케이스 종류의 꾸미기 화면으로 이동한다.
- 리뷰, 찜, 평점은 넣지 않는다.

### 꾸미기

- 꾸미기 화면은 헤더와 푸터 없이 편집에 집중하는 전체 화면으로 만든다.
- 배치: 위쪽에 상단 바, 가운데에 케이스 캔버스, 오른쪽에 세로 도구 버튼. 도구 버튼을 누르면 어떤 버튼이든 화면 아래쪽에 패널이 가로로 열린다. (케이스를 가리지 않는다.) 같은 버튼을 다시 누르거나 캔버스를 누르면 닫힌다.
- 상단 바: ← 뒤로, ? 도움말, 되돌리기, 다시 실행, 전체 초기화, 완료
  - ← 뒤로: 상품 상세로 이동한다. 꾸민 내용이 있으면 나가기 안내창을 띄운다.
  - ? 도움말: 사용 방법 안내창을 띄운다. (스티커 붙이기, 이동·크기·회전·삭제)
  - 되돌리기, 다시 실행: 마지막 동작을 취소하거나 다시 실행한다.
  - 전체 초기화: "꾸민 내용을 모두 지울까요?" 확인창을 띄운다. 지우면 스티커·큐빅·각인이 모두 지워지고, 케이스 색은 그대로 유지된다.
  - 완료: 확인 화면으로 이동한다. 스티커·큐빅·각인이 하나도 없으면 비활성화한다.
- 케이스 캔버스
  - 바깥 점선은 케이스 전체, 안쪽 점선은 꾸밀 수 있는 범위다. 스티커는 안쪽 점선 안에서만 움직인다.
  - 꾸밀 수 있는 면: 쿠션 팩트 뚜껑 윗면 하나
  - 편집 영역 왼쪽 위에 확대·축소(축소, 확대, 리셋)를 둔다. (아래쪽은 도구 패널 자리)
  - 빈 케이스에서 시작한다. 큐빅·스티커 패널을 처음 열면 케이스 위 가운데에 아이콘과 "드래그해주세요" 안내가 잠깐 보였다가 서서히 사라진다.
- 도구 버튼 5개 (오른쪽 세로, 자주 쓰는 순서대로 위에서 아래로)
  - 케이스 색: 색 동그라미 패널. 첫 번째 색이 선택된 상태로 시작한다. 꾸미는 도중에도 바꿀 수 있고, 붙인 스티커는 그대로 유지된다. (밀크 화이트(기본), 블러시 핑크, 라벤더, 스카이 블루, 코코아 베이지 5가지)
  - 큐빅: 실제로 붙이는 파스텔 아크릴 보석 목록 패널 (8개: 핑크 하트, 라벤더 별, 투명 원, 스카이 블루 하트, 핑크 꽃, 샴페인 원, 코랄 별, 진주)
  - 스티커: 곰돌이, 곰돌이 얼굴, 리본, 하트 풍선, 딸기 케이크, 체리, 꽃다발, 별 달린 구름 8개 목록 패널 (가는 브라운·로즈 외곽선에 연한 파스텔 채색, 평평하게 인쇄된 다꾸풍 일러스트 (곰돌이는 점 눈과 작은 입만))
  - 각인: 각인 스타일 목록과 입력창 패널
  - 케이스 종류 (맨 아래, 구분선으로 위 버튼들과 나눔): 상품 상세에서 이미 고르고 들어오므로 가끔 쓰는 버튼이다. 종류 목록 패널. 꾸민 내용이 있는 상태에서 다른 종류를 고르면 "종류를 바꾸면 꾸민 내용이 사라져요" 안내창을 띄운다. 바꾸면 스티커는 지워지고 케이스 색은 유지된다.
- 스티커 공통 규칙 (큐빅, 스티커, 각인 모두 같음)
  - 스티커는 인쇄하고, 큐빅은 실제로 붙이고, 각인은 글자를 새긴다.
  - 개수 제한 없이 꾸밀 수 있는 범위 안에서 자유롭게 붙인다.
  - 패널마다 6~8개를 보여준다. 모든 케이스 종류와 색에 공통이다.
  - 스티커는 클릭하거나 끌어서 붙인다. 클릭하면 케이스 가운데에, 끌어서 안쪽 점선 안에 놓으면 놓은 자리에 붙고 선택 상태가 된다. 끄는 동안 반투명한 스티커가 마우스를 따라오고, 안쪽 점선 밖에 놓으면 붙지 않는다. (각인은 클릭으로 붙인다. 아래 "각인" 참고)
  - 선택 상자: 드래그로 이동, 모서리 핸들로 크기 조절, 회전 핸들로 회전, 삭제(X)로 그 스티커 하나만 지운다.
  - 붙인 스티커를 클릭하면 다시 선택된다. 케이스의 빈 곳을 클릭하면 선택이 풀린다.
  - 같은 스티커를 여러 번 붙일 수 있고, 겹쳐도 된다. 나중에 붙인 스티커가 위에 올라간다.
- 각인
  - 각인 패널의 목록은 각인 스타일이다. 각인 스타일은 글꼴과 각인 색이 한 세트로 정해진 꾸밈이다. (글꼴 2개 × 각인 색 3개 = 6가지, 예: 세리프 · 샴페인 골드)
  - 각인 스타일 6개를 칸마다 같은 예시 문구("각인")로 보여주고, 칸 아래에 스타일 이름을 적는다.
  - 각인 색은 각인 스타일에 포함되어 있어 따로 고르지 않는다. (샴페인 골드, 로즈 골드, 실버)
  - 각인 스타일을 클릭하면 케이스 가운데에 "각인 입력" 문구가 그 스타일로 나타나고 선택 상태가 된다. 동시에 패널에 입력창이 나타난다.
  - 입력창에 문구를 입력하면 케이스 위 글자가 실시간으로 바뀐다. ("붙이기" 버튼은 두지 않는다.)
  - 입력창에는 글자 수(0/10)를 표시하고, 10자를 넘으면 더 입력되지 않는다.
  - 아무것도 입력하지 않은 채 선택을 풀면 "각인 입력" 문구는 사라진다.
  - 붙인 각인을 클릭하면 다시 선택되고, 입력창에서 문구를 고칠 수 있다.

### 확인

- 확인 화면에 보여줄 내용: 페이지 제목, 상품 카드, 주문 제작 상품 안내, 제작·배송 기간 안내, 하단 고정 바(총 금액 + 장바구니 담기 + 바로 구매하기).
- 상품 카드: 쇼핑몰 장바구니처럼 왼쪽에 꾸민 케이스 이미지, 오른쪽에 케이스 종류 이름, 선택 요약(케이스 색, 붙인 스티커·큐빅·각인), 가격을 한 카드에 보여준다.
- 꾸민 케이스 이미지를 누르면 미리보기 창이 떠서 크게 볼 수 있다. 이미지 아래에 "이미지를 누르면 꾸민 상품을 볼 수 있어요" 같은 안내 문구를 둔다.
- 가격은 케이스 종류별 고정 가격이다. (스티커 수와 상관없이 같다.)
- 주문 제작 상품 안내: 꾸민 디자인은 케이스에 인쇄·각인되고 큐빅은 실제로 붙인다는 것과, 직접 꾸민 주문 제작 상품이라 단순 변심에 의한 교환·환불이 어렵다는 안내를 보여준다.
- 제작·배송 기간 안내: 주문 제작 기간과 배송 기간을 보여준다.
- 하단 고정 바에 "장바구니 담기"와 "바로 구매하기"를 나란히 둔다. "장바구니 담기"는 장바구니에 넣고 장바구니로 이동하고, "바로 구매하기"(핵심 행동)는 주문 정보로 바로 이동한다.
- 꾸미기로 돌아갈 때는 네비게이션 바의 ← 뒤로를 쓴다. (꾸민 상태 유지)

### 장바구니

- 장바구니 화면에 보여줄 내용: 페이지 제목, 담은 케이스 목록, 하단 고정 바(총 금액 + 주문하기).
- 담은 케이스 목록: 꾸민 케이스마다 카드 하나. 카드에는 꾸민 케이스 이미지, 케이스 종류 이름, 케이스 색, 붙인 스티커·큐빅·각인, 가격, "수정하기", 삭제 X를 둔다.
- 꾸민 케이스는 하나하나가 다른 디자인이라 수량 선택은 두지 않는다. 같은 걸 더 사려면 다시 꾸며서 담는다.
- "수정하기": 이 디자인을 꾸미기 화면에서 고친다. 꾸미기 화면의 "완료" 버튼이 "수정완료"로 바뀐다. 확인 화면에서 "장바구니 담기"를 누르면 새 카드가 생기지 않고 원래 카드 자리에 고친 디자인이 들어간다(카드 수 그대로). 중간에 나가면 원래 디자인은 그대로다. "바로 구매하기"를 누르면 고친 디자인만 주문하고 장바구니는 그대로 둔다.
- 꾸미기 화면은 평소처럼 열린다. 색·스티커·큐빅·각인 등 원하는 것을 골라 무엇이든 바꿀 수 있다.
- 같은 디자인을 하나 더 사거나 조금 바꿔 하나 더 만드는 기능(복사·수량)은 두지 않는다. 주요 방문자가 본인이 쓸 케이스를 사는 사람이라 쓰임새가 적고, 주문 제작이라 실수 주문을 막기 위해서다. 필요하면 처음부터 다시 꾸민다.
- 총 금액: 담은 케이스 가격의 합계
- "주문하기"를 누르면 담은 케이스를 한 번에 주문하러 주문 정보로 이동한다. (로그인 없이 주문)
- 담은 게 없으면 "장바구니가 비었어요" 문구를 보여준다.

### 주문 정보

- 배송 정보: 받는 사람, 연락처, 주소(주소 + 상세 주소)를 입력한다. 모두 필수 항목이다.
- 결제 수단: 카드, 간편결제, 무통장 입금 중 하나를 고른다. (필수, 가상 사이트라 실제 결제창은 없다.)
- 동의: 구매 조건 확인 동의, 개인정보 수집·이용 동의 체크박스 2개를 둔다. (둘 다 필수)
- 금액: 상품 금액(바로 구매는 케이스 1개 가격, 장바구니 주문은 담은 케이스 합계) + 배송비 = 총 결제 금액을 보여준다.
- 필수 항목 이름 옆에 * 표시를 한다.
- 연락처 형식이 틀리면 칸 아래에 오류 문구를 보여준다.
- 필수 항목(받는 사람, 연락처, 주소, 결제 수단, 동의 2개)을 모두 채워야 "결제하기" 버튼이 활성화된다.
- "결제하기"를 누르면 주문 완료 화면으로 이동한다.
- 확인 또는 장바구니(온 곳)로 돌아갈 때는 네비게이션 바의 ← 뒤로를 쓴다.

### 주문 완료

- 주문이 끝났다는 완료 화면을 따로 둔다.
- 완료 영역은 가운데 정렬로, 위에서부터 완성 케이스 이미지 → 완료 문구 → 주문 정보 상자 → "이미지 저장하기" 버튼 순서로 둔다. (확인 화면의 카드 형태와 다르게, 완성한 기쁨을 주는 화면)
- 완성 케이스 이미지: 완료 체크 표시 자리에 방문자가 완성한 케이스 이미지를 둔다. 장바구니로 여러 개 주문하면 첫 번째 케이스 이미지와 "외 n개"를 보여준다. 반짝임 효과를 주고, 누르면 미리보기 창이 떠서 크게 볼 수 있다. 이미지 아래에 확인 화면과 같은 안내 문구("이미지를 누르면 꾸민 상품을 볼 수 있어요")를 둔다.
- 완료 문구: 주문이 끝났다는 안내와 짧은 부가 문구 (문구는 추후 결정)
- 주문 정보 상자: 주문번호, 주문일자, 예상 배송일 (예상 배송일은 제작·배송 기간이 정해지면 결정)
- "이미지 저장하기" 버튼: 누르면 완성한 케이스 이미지를 저장한다. 아이폰·아이패드는 공유 창의 "이미지 저장"으로 사진첩에(버튼 아래 안내 문구), 안드로이드는 갤러리 Download 앨범에, 데스크탑은 다운로드 폴더에 저장된다.
- "공유하기" 버튼 (공유를 지원하는 기기(휴대폰·데스크탑)에서만, 지원하지 않는 브라우저에서는 숨김): 저장 버튼 아래. 꾸민 케이스 이미지를 카카오톡·인스타그램 등으로 보낸다.
- 주문 요약: 배송지, 결제 수단, 총 결제 금액을 보여준다. (케이스 종류·색·스티커는 완성 이미지로 확인)
- 배송·문의 안내: 제작·배송 기간, 문자 안내, 주문 문의 방법을 보여준다.
  - 문자 안내: "주문 내용은 입력한 연락처로 문자로 보내드려요" (주문번호와 주문 내용을 문자로 보냄)
  - 주문 문의 방법: 주문번호 또는 받는 사람 이름과 연락처로 고객센터에 문의 (주문번호를 몰라도 문의 가능)
  - 계정이 없어도 주문 완료 화면과 문자로 주문 내용을 확인할 수 있다.
- "홈으로 가기" 버튼은 두지 않는다. (네비게이션 바의 로고로 대신)

### 넣지 않기로 한 것

- 스타일(분위기) 선택 메뉴 (케이스 종류 + 케이스 색으로 바꿈)
- 뒷면(바닥면) 꾸미기 (뚜껑 윗면만 꾸밈)
- 진행 단계 표시
- 스티커를 붙일 때 애니메이션 효과
- 스티커 호버 미리보기
- 추천 조합·디자인 템플릿, 이미지 업로드
- 되돌리기 단축키(Ctrl+Z)
- 확인 화면의 사용 장면 목업
- 각인 "붙이기" 버튼 (입력하면 실시간으로 반영)
- "디자인 완료" 확인창 (확인 화면이 같은 역할)
- 확인·주문 정보 화면 아래쪽의 "이전으로" 버튼 (네비게이션 바의 ← 뒤로로 대신)
- 꾸미기 화면의 설정 버튼
- 계정 기능: 로그인, 회원가입, 마이페이지 (로그인 없이 주문, 필요하면 다시 결정)
- 리뷰, 찜(하트), 평점, 할인율 표시 (메인의 "직접 꾸민 후기" 섹션은 예외로 둠)
- 후기 평균 별점·후기 수, 후기 "더보기"와 후기 목록 페이지, 후기 작성 기능
- 수량 선택, 배송 요청사항, 우편번호 검색 (이번에는 넣지 않음) · 전체 동의는 "모두 동의"로 추가함
