# 모아(MOA)

나만의 쿠션 케이스, 모아에서 완성해요.

모아는 방문자가 케이스 종류와 색을 고르고, 스티커·큐빅·각인으로 직접 꾸민 쿠션 케이스를 확인하고 주문하는 사이트예요. 주요 방문자는 본인이 쓸 케이스를 꾸미려는 10대 후반~20대 초반 여성이에요. 이 디자인 시스템은 시각 디자인 시안(P01~P07 페이지, M01~M07 안내창)과 실제 사이트 코드에서 쓰는 값만 모았어요. (2026-11-17 사이트 기준)

## 분위기와 말투

- 감성적이고 아기자기하며 예쁜 느낌. 아기자기함은 화면 장식보다 스티커·일러스트·작은 반짝이 같은 디테일로 표현해요.
- 화면 구성은 깔끔하게. 복잡하고 정신없는 화면은 피해요.
- 말투는 부드러운 해요체예요. 예: "꾸민 디자인은 케이스에 인쇄되고, 큐빅은 실제로 붙여 드려요", "이미지를 누르면 꾸민 상품을 볼 수 있어요", "꾸민 내용이 사라져요".
- 버튼은 하는 일을 그대로 적어요: 꾸미기 시작, 완료, 장바구니 담기, 바로 구매하기, 결제하기, 주문하기.
- 사이트의 문구와 값은 모두 정해져 있어요. 가격은 원형 19,000원 · 둥근 정사각형 20,000원 · 하트 21,000원 · 꽃 22,000원이에요.

## 컬러

베이지를 섞은 소프트 핑크·코랄 톤이에요. 밝은 테마 하나만 써요.

| 역할 | 토큰 | 값 |
| --- | --- | --- |
| 페이지 배경 | `bg-page` | #FBF6F0 |
| 카드·바·안내창 | `bg-surface` | #FFFFFF |
| 면 (배너, 이미지 자리, 선택한 항목) | `bg-soft` | #F7E6DF |
| 푸터 | `bg-footer` | #F3EAE1 |
| 기본 테두리 | `line` | #EADFD5 |
| 버튼·입력창 테두리 | `line-strong` | #E3D3C7 |
| 포인트 (핵심 버튼, 가격, 로고) | `accent` | #C4513F |
| 핵심 버튼 호버 | `accent-hover` | #B04634 |
| 본문 글자 | `ink` | #3D2E28 |
| 보조 글자 | `ink-muted` | #6F5D54 |
| 오류 | `error` | #B23B34 |

- `accent`는 아껴 써요. 한 화면에서 핵심 버튼 하나, 가격, 로고, 필수 표시(*)에만 써요.
- `accent` 위 글자는 항상 흰색(`on-accent`)이에요. 명암 4.6:1로 기준을 넘어요.
- `bg-soft` 위에 `accent` 작은 글자를 쓰면 3.8:1로 기준(4.5:1)에 못 미쳐요. 그래서 P03 도구 버튼에서 선택한 이름(2026-11-23)과 호버한 테두리 버튼의 글자·테두리(2026-11-24)는 `accent-hover`(4.6:1)로 써요.
- 장식 색(`deco-coral`, `deco-peach`, `deco-icon`)은 별점, 반짝이, 이미지 자리 아이콘에만 써요. 글자에는 쓰지 않아요.

## 케이스와 꾸미기

- 케이스 종류: 원형, 둥근 정사각형, 하트, 꽃. 바깥 모양이 달라도 안쪽 홈은 모두 둥근 원형이에요.
- 케이스 색 5가지 (순서대로): 밀크 화이트 `case-milk-white`(기본) → 블러시 핑크 `case-blush-pink` → 라벤더 `case-lavender` → 스카이 블루 `case-sky-blue` → 코코아 베이지 `case-cocoa-beige`.
- 꾸미기 도구: 케이스 색, 큐빅(실제 아크릴 큐빅을 붙임), 스티커(곰돌이·리본 등 파스텔 일러스트, 인쇄), 각인(10자 이내 글자), 케이스 종류.
- 각인 스타일: 글꼴 2개(세리프: Cormorant Garamond + 고운바탕, 모던: Pretendard 600) × 각인 색 3개(샴페인 골드 `engrave-gold`, 로즈 골드 `engrave-rose`, 실버 `engrave-silver`) = 6가지. 각인 1개는 최대 10글자예요.
- 가격: 원형 19,000원 · 둥근 정사각형 20,000원 · 하트 21,000원 · 꽃 22,000원. 스티커·큐빅은 5개까지 추가 요금 없음, 6개째부터 1개당 +500원, 각인 1개당 +1,500원(최대 10글자). 배송비는 전 상품 무료예요.
- 꾸밈 이미지는 미니멀 엘레건스: 요소 2~3개, 통통하고 반짝이는 파스텔 아크릴 큐빅, 넉넉한 여백. 원색은 쓰지 않아요.
- 스티커는 가는 브라운·로즈 외곽선에 연한 파스텔 채색, 평평하게 인쇄된 다꾸풍 일러스트예요 (곰돌이는 점 눈과 작은 입만).

## 타이포그래피

- 제목·본문 모두 **Pretendard** (v1.3.9, SIL Open Font License). 디자인에서 쓰는 굵기 4개만 `fonts/`에 웹용 woff2로 넣었어요: Regular 400, SemiBold 600, Bold 700, ExtraBold 800. 라이선스는 `fonts/Pretendard-LICENSE.txt`.
- P01 소개 배너에만 영문 필기체 **Great Vibes** 한 줄("Make it yours")을 `accent` 색으로 써요. 다른 곳에는 쓰지 않아요.
- 제목은 800, 버튼은 700, 라벨은 600, 본문은 400이에요.
- 크기 단계: 52(필기체) → 48 → 36 → 30 → 28 → 24 → 22 → 20 → 18 → 16 → 14px.
- 글자는 14px 이상, 짝수(14·16·18…)만 써요. 13px 이하나 홀수 크기는 쓰지 않아요.
- 줄바꿈은 낱말 단위예요(`word-break: keep-all`). "각인", "최대" 같은 낱말이 중간에서 끊기지 않고, 칸보다 긴 낱말만 중간에서 끊어요(`overflow-wrap: break-word`). (2026-11-18)

## 간격, 모서리, 그림자

- 간격은 4px 단위예요. 페이지 좌우 여백 32px, 내용 최대 너비 1200px, 화면 프레임 1440px, 안내창 480px.
- 섹션 사이는 80~96px로 넉넉하게 둬서 깔끔하게 보이게 해요.
- 모서리는 둥글게. 버튼·탭·태그·배지는 모두 알약 모양(`radius-pill`), 카드는 20px, 안내창과 큰 상자는 28px, 소개 배너는 32px.
- 그림자는 연하게, 핵심 버튼(`shadow-cta`)과 케이스 종류 카드(`shadow-card`), 떠 있는 바와 패널에만 써요.

## 아이콘과 이미지

- 아이콘은 선형 SVG예요. 선 굵기 1.8~2px, 끝과 꺾임은 둥글게, 색은 글자 색을 따라가요. 이모지는 쓰지 않아요.
- 반짝이(네 갈래 별)는 모아의 작은 장식이에요. 배너, 안내 문구 앞, 완료 이미지 주변에만 한두 개씩 둬요.
- 로고는 글자 로고로 확정했어요("MOA" 아래 줄에 "모아", 가운데 정렬). 사이트 화면에서는 로고 이미지를 쓰지 않고 글자로 그려요. 같은 로고를 외곽선으로 바꾼 파일은 `src/assets/logo.svg`예요. 파비콘은 "MOA" 한 줄(`accent`, 800, 배경 투명).
- 케이스 목업, 예시 상품, 후기 사진, 스티커, 제작 안내 아이콘, 꾸민 예시 이미지는 `src/assets`의 페이지별 폴더(`p01-main`·`p02-detail`·`p03-customize`)에 있어요. 이미지가 뜨기 전에는 `bg-soft` 면이 보여요.

## 움직임

- 움직임은 0.3초, 부드럽게(ease). 마우스를 올린 카드 하나에서만 움직이고 화면 전체는 움직이지 않아요.
- 케이스 종류 카드: 마우스를 올리면 꾸미지 않은 케이스가 꾸민 예시 이미지로 서서히 바뀌어요("꾸민 예시" 표시).
- 후기 카드: 평소에는 한 줄까지만 보이고 넘치면 "…"으로 줄여요. 마우스를 올리면 이미지가 1.05배 확대되고, 한 줄 후기가 옆으로 흐르며 끝까지 보여 줘요. 카드 크기는 그대로예요.
- 키보드로 선택했을 때도 같은 모습을 보여 주고, 움직임을 줄이는 설정에서는 바로 바뀌어요.
- 소개 배너: 처음 들어올 때 문구가 살짝 올라오며 나타나고, 이어서 사진이 살짝 올라와요(사진은 처음부터 보여요). 사진이 나타난 뒤 하얀 빛줄기가 대각선으로 한 번 지나가요(모든 기기).
- 완성 이미지(P06): 이미지가 살짝 커지며 나타나고, 체크 배지가 도장처럼 찍힌 뒤 빛줄기가 한 번 지나가요. 이어서 반짝이 별 3개가 차례로 나타나 은은하게 반짝여요. 아래 문구·주문 정보·버튼은 차례로 살짝 올라와요(전체 약 1.3초). 데스크탑에서는 이미지에 마우스를 올리면 빛줄기가 한 번 더 지나가요.
- 버튼 호버는 진한 코랄(`accent-hover`) 또는 `bg-soft` 배경(테두리 버튼은 `bg-soft` 배경 + `accent-hover` 글자·테두리), 누르면 0.98배로 살짝 작아져요.
- 안내창: 어두운 배경이 서서히 나타나고 창은 0.96배에서 원래 크기로 커지며 등장(0.2초), 닫을 때는 반대로(0.18초).
- 도구 패널(P03): 화면 아래에서 12px 올라오며 나타나요(0.25초).
- 반짝이 아이콘: 살짝 커지며 돌았다가 원래대로 (3.6초마다 반복).
- 휴대폰·태블릿(터치 기기)에서는 마우스를 올릴 때만 나오는 효과(카드 이미지 바뀜, 후기 확대·흐름)와 커스텀 커서를 쓰지 않아요.
- 넣지 않는 움직임: 스티커 붙일 때 애니메이션, 스티커 호버 미리보기.

## 휴대폰·태블릿

폭 1024px 이하 터치 기기에 맞춘 화면을 덧붙였어요. 휴대폰과 태블릿은 폭 768px로 나눠요. 데스크탑(1025px 이상) 화면은 그대로예요.

- 네비게이션 바 높이 56px(767px 이하), P01·P06 메뉴는 왼쪽 햄버거 버튼 안으로 들어가요.
- P01 케이스 종류 카드는 휴대폰에서 2×2, 후기는 손가락으로 옆으로 넘겨요(휴대폰 1.2개, 태블릿 2.2개 보임).
- P03 꾸미기: 상단 바 56px, 오른쪽 도구 버튼 줄 폭 64px·버튼 하나 높이 56px, 패널 높이 화면의 45%까지. 큐빅·스티커는 탭해서 붙이고, 두 손가락으로 크기·회전을 바꿔요.
- P05 동의 줄은 줄 전체가 눌리고 높이 44px, 결제하기는 화면 아래에 고정돼요.
