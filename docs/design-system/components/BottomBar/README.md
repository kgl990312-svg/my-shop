# BottomBar

P02·P04·P07에서 화면 아래에 항상 붙어 있는 바로, 왼쪽에 금액, 오른쪽에 핵심 버튼을 둬요.

- 거의 불투명한 흰 배경, 위 테두리 1px `line`, `shadow-bar`. 위아래 16px, 좌우 32px.
- 왼쪽: "총 금액" 16px `ink-muted` + 금액 24px 800 (P02는 종류 이름 + 가격).
- 오른쪽: P02 꾸미기 시작 / P04 장바구니 담기(테두리) + 바로 구매하기(핵심) / P07 주문하기.
- 푸터 바로 위 순서에 두고 sticky로 화면 아래에 고정해요.
- 휴대폰: 금액과 버튼을 한 줄에 두고(P04는 총 금액 한 줄 + 버튼 2개 나란히), P05 결제하기도 화면 아래에 고정해요.
