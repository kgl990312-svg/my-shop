# Dialog

화면 위에 뜨는 안내창으로, 너비 480px, 흰 배경, 모서리 `radius-2xl`(28px)이에요.

- 확인 안내창 (M01 나가기, M02 전체 초기화, M05 종류 변경): 가운데 `bg-soft` 원 아이콘(56px, `accent`) + 제목 22px 800 + 아래 두 버튼(취소 soft / 실행 primary, 54px). 높이 300px.
- 내용 안내창 (M03 이용약관, M04 개인정보처리방침, M06 도움말): 제목 22px 800 + 스크롤되는 `bg-subtle` 내용 상자(`ink-soft` 14px) + 닫기(dark). 높이 600px.
- M07 미리보기: `overlay-dim` 전체 화면 위에 꾸민 케이스 이미지를 크게(`radius` 36px, `shadow-preview`), 오른쪽 위 닫기 X. 바깥을 눌러도 닫혀요.
- 후기 안내창: P01 후기 카드를 누르면 사진·별점·작성자·날짜·전체 문구·케이스 종류를 크게 보여 주고, ←/→ 버튼과 키보드 방향키로 다른 후기로 넘겨요.
- 이미지 저장 안내창: 아이폰·아이패드에서 P06 "이미지 저장하기"를 누르면 완성 이미지를 크게 띄워, 길게 눌러 사진 앱에 저장하게 해요.
- 열고 닫기: 어두운 배경이 서서히 나타나고 창은 0.96배에서 원래 크기로 커지며 등장(0.2초), 닫을 때는 반대로(0.18초).
- 확인 안내창 문구는 결과를 짧게 말해요: "꾸민 내용이 사라져요", "꾸민 내용을 모두 지울까요?", "종류를 바꾸면 꾸민 내용이 사라져요".
