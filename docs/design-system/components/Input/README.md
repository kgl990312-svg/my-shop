# Input

P05 주문 정보의 글자 입력창으로, 위에 라벨을 두고 필수 항목은 `accent` 별표(*)를 붙여요.

- 높이 52px, 모서리 `radius-md`(14px), 1.5px `line-strong` 테두리, 흰 배경, 16px.
- 라벨 16px 600, 라벨과 입력창 사이 8px. 안내 문구 색은 `placeholder`.
- 오류: 테두리와 문구를 `error`로, 칸 바로 아래에 아이콘과 함께 14px. 입력칸에서 나갔을 때 보여 줘요. 예: "받는 사람을 입력해 주세요", "연락처 형식을 확인해 주세요 (예: 010-1234-5678)".
- 연락처는 숫자만 입력해도 하이픈이 자동으로 들어가요(010-1234-5678).
- 입력 묶음(배송 정보 등)은 흰 카드(`radius-xl`, 1px `line`, 안쪽 여백 32px)에 넣고 항목 사이 20px.
