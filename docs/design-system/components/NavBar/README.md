# NavBar

모든 페이지(P03 꾸미기 제외) 맨 위의 네비게이션 바로, 왼쪽 뒤로·가운데 로고·오른쪽 장바구니를 둬요.

- 높이 72px, `bg-surface`, 아래 테두리 1px `line`. 세 칸 그리드(1fr auto 1fr).
- ← 뒤로: P02·P04·P05·P07에만. P01·P06에는 없어요 (P06은 다시 결제 방지).
- 메뉴: P01·P06에만 왼쪽에 "홈 · CASE · REVIEW"(16px 700, 자간 0.04em, 사이 32px). 누르면 P01의 맨 위·케이스 종류·직접 꾸민 후기로 가요. 주문 과정(P04·P05)에는 두지 않아요.
- 장바구니: 담긴 개수 배지(`accent` 원 22px, 흰 글자 14px 700). 비어 있으면 배지를 숨겨요.
- 아이콘 버튼은 44×44px 터치 영역, 아이콘 24px, 선 1.8~2px. `aria-label`을 꼭 달아요.
- 휴대폰(767px 이하): 높이 56px, 로고를 조금 줄이고, 메뉴는 왼쪽 햄버거 버튼 안으로 들어가요(바깥을 누르거나 Esc로 닫힘).
- P03 꾸미기는 이 바 대신 상단 바(뒤로, 도움말, 되돌리기, 다시 실행, 전체 초기화, 완료)를 써요.
