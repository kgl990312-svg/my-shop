# 모아(MOA) 디자인

## 기준

- 데스크탑 기준 (화면 프레임 너비 1440, 안내창 너비 480)
- docs/01-site-purpose.md, docs/02-site-structure.md, docs/04-site-wireframe.md, PROJECT_CONTEXT.md, 사용자 답변을 바탕으로 작성했다.
- 와이어프레임의 구조와 섹션 순서는 바꾸지 않고, 컬러·글꼴·간격·모서리·컴포넌트 모양만 정했다.
- 디자인 시스템과 이 문서의 내용은 같다.

## 링크

- 디자인 시스템: 모아(MOA) — https://claude.ai/artifact/Kwi1LcyK45R2Kf2EfnbtMZ
- 시각 디자인 시안: 모아(MOA) 시각 디자인 (P01~P07, M01~M07) — https://claude.ai/code/artifact/91e250c0-6355-4eb6-91d9-81de296f63b7

## 분위기와 말투

- 감성적이고 아기자기하며 예쁜 느낌. 아기자기함은 화면 장식보다 스티커·일러스트·작은 반짝이 같은 디테일로 표현한다.
- 화면 구성은 깔끔하게. 복잡하고 정신없는 화면은 피한다.
- 말투는 부드러운 해요체. 예: "나만의 쿠션 케이스, 모아에서 완성해요", "꾸민 디자인은 케이스에 인쇄되고, 큐빅은 실제로 붙여 드려요", "꾸민 내용이 사라져요"
- 버튼은 하는 일을 그대로 적는다: 꾸미기 시작, 완료, 장바구니 담기, 바로 구매하기, 결제하기, 주문하기
- 아직 정하지 않은 문구는 [가격], [케이스 종류 이름]처럼 대괄호로 비워 둔다.

## 7. 아이콘·이미지

- 아이콘은 선형 SVG. 선 굵기 1.8~2px, 끝과 꺾임은 둥글게, 색은 글자 색을 따른다. 이모지는 쓰지 않는다.
- 반짝이(네 갈래 별)는 모아의 작은 장식이다. 배너, 안내 문구 앞, 완료 이미지 주변에만 한두 개씩 둔다.
- 로고는 글자 로고로 확정했다 ("MOA" 아래 줄에 "모아", 가운데 정렬). 로고 이미지는 쓰지 않는다.
- 파비콘: 작은 크기에서도 읽히도록 로고 윗줄 "MOA"만 한 줄로 쓴다 (포인트 코랄, 800, 배경 투명). 파일은 public/favicon.png
- 이미지는 src/assets/site의 실제 이미지를 쓴다. 이미지가 뜨기 전에는 면 색(#F7E6DF)이 보인다.
- P02 상품정보의 상세 이미지는 높이를 고정하지 않고 사진 원래 비율로 보여 준다.
- P03 케이스는 흰색 케이스 윗면 이미지(배경 투명)에 케이스 색을 곱하기(multiply)로 입힌다.
- 필요한 이미지: 케이스 목업, 소개 배너 예시 상품, 예시 후기 사진, 스티커, 제작 안내 아이콘, 케이스 종류별 꾸민 예시 이미지(종류마다 1장)

### 꾸밈 이미지 방향 (미니멀 엘레건스)

- 케이스 종류: 원형, 둥근 정사각형, 하트, 꽃. 안쪽 홈은 모두 둥근 원형
- 메인 케이스 종류 카드와 P02 이미지는 밀크 화이트 케이스, 소개 배너는 블러시 핑크 케이스
- 한 케이스에 요소 2~3개만, 한쪽에 모아 배치하고 나머지는 여백
- 큐빅: 뒷면이 평평한 아크릴 보석, 통통하고 반짝이는 다면 커팅 (핑크 하트, 라벤더 별, 투명 원, 스카이 블루 하트, 핑크 꽃, 샴페인 원, 코랄 별, 진주). 색은 파스텔 핑크·라벤더·스카이 블루·투명·샴페인만 쓰고 빨강·주황·초록은 쓰지 않는다. 실제로 붙어 살짝 도톰하다
- 스티커: 가는 브라운·로즈 외곽선에 연한 파스텔 채색, 광택 뚜껑에 평평하게 인쇄된 다꾸풍 일러스트 (곰돌이, 곰돌이 얼굴, 리본, 하트 풍선, 딸기 케이크, 체리, 꽃다발, 별 달린 구름). 곰돌이 얼굴은 점 눈과 작은 입만. 원색, 굵은 외곽선은 쓰지 않는다
- 각인: 이름·이니셜처럼 짧은 글자 (예: 배너 "Moa", 후기 "Y.J.")

## 8. 컴포넌트

### 로고

- "MOA" 800, 자간 0.12em, 포인트 코랄 / "모아" 600, 보조 글자. 두 줄, 가운데 정렬, 줄 간격 1.15
- 네비게이션 바: 30px / 14px, 바 가운데. 누르면 P01 메인 (P04·P05에서 꾸민 내용이 있으면 M01)

### 네비게이션 바

- ← 뒤로는 P02·P04·P05·P07에만 둔다. P01·P06에는 없다.
- 장바구니 배지: 포인트 코랄 원, 흰 숫자 11px 700. 비어 있으면 숨긴다.
- 아이콘 버튼 44×44px, 아이콘 24px
- P03 꾸미기는 이 바 대신 상단 바(뒤로, 도움말, 되돌리기, 다시 실행, 전체 초기화, 완료)를 쓴다.
