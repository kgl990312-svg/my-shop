# 모아(MOA) 사이트 목적

## 1. 사이트 목적 한 문장

방문자가 케이스 종류와 색을 고르고 스티커로 직접 꾸민 나만의 쿠션 케이스를 확인하고 주문하는 사이트

### 기획 배경

- 폰케이스나 옷은 내 취향대로 꾸밀 수 있는데, 매일 꺼내 쓰는 화장품은 왜 내 마음대로 꾸밀 수 없을까?
- 이 생각에서 직접 꾸민 나만의 쿠션 케이스를 만들 수 있는 사이트, 모아를 기획했다.

### 브랜드 이름의 뜻

- **모아(MOA)**: "모으다·모이다"에서 온 이름. 큐빅, 스티커, 각인을 모아 나만의 쿠션 케이스를 완성한다는 뜻

## 2. 주요 방문자와 방문자의 필요

- **주요 방문자**: 본인이 쓸 케이스를 꾸미려는 10대 후반~20대 초반 여성 (고등학생, 대학생, 사회초년생)
- **방문자의 특징** (기획을 위한 가정)
  - 다꾸(다이어리 꾸미기), 폰꾸(폰 꾸미기)처럼 내 물건을 꾸미는 걸 좋아하고 스티커를 모은다.
  - 내 취향이 담긴 물건을 SNS에 올리고 친구에게 자랑한다.
  - 쿠션 팩트를 파우치에 넣고 매일 들고 다니며, 남들 앞에서도 자주 꺼낸다.
- **구매 습관** (기획을 위한 가정)
  - 부담 없는 가격의 작은 소품을 자주 산다.
  - 회원가입이나 복잡한 결제 과정을 귀찮아한다.
- **방문자의 필요**: 남들과 다른 나만의 물건, 직접 꾸미는 재미, 완성한 걸 자랑하는 즐거움
- **사용 환경**: 데스크탑 기준 (꾸미기는 큰 화면이 편해서 데스크탑부터 설계, 모바일은 그 위에 덧붙여 대응함)

### 방문자 특징과 사이트 기능

| 방문자 특징 | 사이트 기능 |
|---|---|
| 꾸미기·스티커를 좋아함 | 스티커로 꾸미는 꾸미기 화면 |
| 완성한 걸 자랑하고 싶음 | 완성 이미지 저장하기 |
| 회원가입을 귀찮아함 | 로그인 없이 구매, 장바구니 |
| 감성적인 취향 | 감성적이고 아기자기한 분위기 |
- **상품**: 화장품 쿠션 팩트의 케이스

## 3. 가장 중요한 행동과 보조적인 행동

- **가장 중요한 행동**: 꾸미기 → 확인 → 주문하기로 이어지는 흐름
- **보조적인 행동**: 케이스 종류 둘러보기 (케이스 종류의 크기와 가격을 비교하고, 상품 상세에서 내 쿠션에 맞는지 확인하기)

### 확정된 사이트 흐름

1. 케이스 종류 중 하나를 고르고, 상품 상세에서 크기·호환 규격·가격·인쇄 방식을 확인한다.
2. 꾸미기 화면에서 케이스 색을 고르고, 케이스(뚜껑 윗면)에 스티커·큐빅·각인을 붙인다.
3. 붙인 스티커는 옮기고, 크기와 회전을 조절하고, 하나씩 지울 수 있다. 필요하면 되돌리기, 다시 실행, 전체 초기화를 쓴다.
4. 완성한 디자인을 확인하고, 장바구니에 담거나 바로 구매한다. 여러 개를 사려면 다시 꾸며서 장바구니에 담는다.
5. 주문 정보(배송 정보·결제 수단)를 입력해 주문한다. 로그인 없이 주문할 수 있다.

### 확정된 구성

- **케이스 종류**: 원형, 둥근 정사각형, 하트, 꽃 4종. 바깥 모양이 달라도 안쪽 홈은 모두 둥근 원형 (크기·가격은 `PROJECT_CONTEXT.md` 6번)
- **직접 꾸민 후기**: 메인 아래쪽에 다른 사람이 꾸민 케이스 후기(사진, 별점, 한 줄 후기)를 가로로 넘겨 보여준다. (예시 후기)
- **상품 상세**: 꾸미기 전에 상품 정보, 제작 안내(제작 과정 단계), 사이즈(호환 규격), 배송·교환 안내를 보여준다.
- **케이스 색**: 꾸미기 화면에서 고른다. 꾸미는 도중에도 바꿀 수 있다. 밀크 화이트(기본), 블러시 핑크, 라벤더, 스카이 블루, 코코아 베이지 5가지
- **재료**: 큐빅(8개), 스티커(8개: 곰돌이, 리본, 하트 풍선 등), 각인(10자 이내)
- **제작 방식**: 스티커와 케이스 색은 인쇄하고, 큐빅은 실제 아크릴 큐빅을 붙이고, 글자는 각인한다.
- **꾸밀 수 있는 면**: 쿠션 팩트 뚜껑 윗면 하나
- **재료 개수**: 꾸밀 수 있는 범위 안에서 자유롭게 붙인다. 스티커·큐빅은 5개까지 추가 요금이 없고 6개째부터 1개당 +500원, 각인은 1개당 +1,500원(최대 10글자)이다.
- **시작 방식**: 빈 케이스에서 시작
- **장바구니**: 꾸민 케이스를 여러 개 담아 한 번에 주문할 수 있다. 로그인 없이 쓴다. (계정 기능은 없음)
- **편집 기능**: 선택 상자(이동, 크기 조절, 회전, 삭제), 되돌리기, 다시 실행, 전체 초기화

## 4. 전달하고 싶은 인상과 피하고 싶은 방향

- **전달하고 싶은 인상**: 감성적이고 아기자기하며 예쁜 (아기자기함은 스티커·일러스트·작은 디테일로, 화면 구성은 깔끔하게)
- **피하고 싶은 방향**: 복잡하고 정신없는 화면

## 5. 기획을 위한 가정

- 2장의 방문자 특징과 구매 습관은 조사 결과가 아니라 기획자의 가정이다. (설문 등으로 확인 필요)
