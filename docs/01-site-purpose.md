# 모아(MOA) 사이트 목적

## 1. 사이트 목적 한 문장

방문자가 케이스 종류와 색을 고르고 스티커로 직접 꾸민 나만의 쿠션 케이스를 확인하고 주문하는 사이트

### 브랜드 이름의 뜻

- **모아(MOA)**: "모으다·모이다"에서 온 이름. 보석 스티커, 리본 스티커, 그림 스티커, 텍스트를 모아 나만의 쿠션 케이스를 완성한다는 뜻

## 2. 주요 방문자와 방문자의 필요

- **주요 방문자**: 본인이 쓸 케이스를 꾸미려는 10~20대 여성
- **방문자의 필요**: 내 취향대로 직접 꾸며보는 재미
- **사용 환경**: 데스크탑 기준
- **상품**: 화장품 쿠션 팩트의 케이스

## 3. 가장 중요한 행동과 보조적인 행동

- **가장 중요한 행동**: 꾸미기 → 확인 → 주문하기로 이어지는 흐름
- **보조적인 행동**: 케이스 종류 둘러보기 (케이스 종류의 크기와 가격을 비교하고, 상품 상세에서 내 쿠션에 맞는지 확인하기)

### 확정된 사이트 흐름

1. 케이스 종류 중 하나를 고르고, 상품 상세에서 크기·호환 규격·가격·인쇄 방식을 확인한다.
2. 꾸미기 화면에서 케이스 색을 고르고, 케이스(뚜껑 윗면)에 스티커와 텍스트를 붙인다.
3. 붙인 스티커는 옮기고, 크기와 회전을 조절하고, 하나씩 지울 수 있다. 필요하면 되돌리기, 다시 실행, 전체 초기화를 쓴다.
4. 완성한 디자인을 확인하고, 장바구니에 담거나 바로 구매한다. 여러 개를 사려면 다시 꾸며서 장바구니에 담는다.
5. 주문 정보(배송 정보·결제 수단)를 입력해 주문한다. 로그인 없이 주문할 수 있다.

### 확정된 구성

- **케이스 종류**: 크기·호환 규격 기준으로 나눈 케이스 종류 (개수와 이름은 추후 결정, 3~4개 추천)
- **직접 꾸민 후기**: 메인 아래쪽에 다른 사람이 꾸민 케이스 후기(사진, 별점, 한 줄 후기)를 가로로 넘겨 보여준다. (예시 후기)
- **상품 상세**: 꾸미기 전에 상품 정보, 제작 안내(제작 과정 단계), 사이즈(호환 규격), 배송·교환 안내를 보여준다.
- **케이스 색**: 꾸미기 화면에서 고른다. 꾸미는 도중에도 바꿀 수 있다.
- **재료**: 보석 스티커, 리본 스티커, 그림 스티커, 텍스트 (모두 케이스에 인쇄)
- **제작 방식**: 꾸민 디자인을 케이스에 그대로 인쇄한다. (입체 재료와 각인은 쓰지 않는다.)
- **꾸밀 수 있는 면**: 쿠션 팩트 뚜껑 윗면 하나
- **재료 개수**: 개수 제한 없이 꾸밀 수 있는 범위 안에서 자유롭게 붙인다.
- **시작 방식**: 빈 케이스에서 시작
- **장바구니**: 꾸민 케이스를 여러 개 담아 한 번에 주문할 수 있다. 로그인 없이 쓴다. (계정 기능은 없음)
- **편집 기능**: 선택 상자(이동, 크기 조절, 회전, 삭제), 되돌리기, 다시 실행, 전체 초기화

## 4. 전달하고 싶은 인상과 피하고 싶은 방향

- **전달하고 싶은 인상**: 감성적이고 아기자기하며 예쁜 (아기자기함은 스티커·일러스트·작은 디테일로, 화면 구성은 깔끔하게)
- **피하고 싶은 방향**: 복잡하고 정신없는 화면

## 5. 기획을 위한 가정

없음

## 6. 다음 단계에서 결정할 내용

- 케이스 종류 구성 (개수, 이름, 크기·호환 규격)
- 케이스 종류별 가격
- 케이스 색 구성 (어떤 색인지)
- 스티커 구성 (보석·리본·그림 스티커의 모양과 색, 텍스트 스타일)
- 꾸밀 수 있는 범위(안쪽 점선)의 크기
- 사이트의 색감과 톤
- 모바일 대응 여부
- 소개 배너에 보여줄 예시 상품 이미지 (어떤 종류·색의 케이스를 보여줄지)
- 예시 후기 내용 (사진, 별점, 한 줄 후기)
- 후기 작성 기능과 후기 목록 페이지 (계정 기능과 함께 필요하면 다시 결정)
- 상품 상세 내용 (상품 설명, 소재, 호환 규격 확인 방법, 상세 이미지)
- 제작·배송 기간
- 배송비 금액
- 주문 제작 상품 안내 문구 (인쇄 안내, 교환·환불)
- 제작 안내 단계 문구·아이콘
- 도움말 내용
- 이용약관, 개인정보처리방침 내용
- 회사 정보, 고객센터 내용
