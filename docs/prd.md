# 요구사항 정의서 (PRD)

- 프로젝트명: 모아(MOA) — 나만의 쿠션 케이스 꾸미기·주문 사이트
- 작성일: 2026-11-17
- 배포 주소: https://kgl990312-svg.github.io/my-shop/
- 기준 문서: `PROJECT_CONTEXT.md` (2026-11-17 기준)

## 1. 프로젝트 개요

- **목적:** 방문자가 케이스 종류와 색을 고르고, 스티커·큐빅·각인으로 직접 꾸민 나만의 쿠션 케이스를 확인하고 주문하는 사이트. 로그인 없이 구매하고, 가상 사이트라 실제 결제는 없다.
- **방문자가 원하는 것:** 남들과 다른 나만의 물건, 직접 꾸미는 재미, 완성한 걸 자랑하는 즐거움 (주요 방문자: 본인이 쓸 케이스를 꾸미려는 10대 후반~20대 초반 여성)
- **핵심 행동:** 꾸미기 → 확인 → 주문하기 (보조 행동: 케이스 종류 둘러보기)

## 3. 미정·제외 항목

**미정**
- 없음. `PROJECT_CONTEXT.md`의 "아직 정하지 않은 사항"은 2026-11-17에 모두 결정됨.
- 실제 휴대폰·태블릿 기기 확인은 2026-11-16에 마침.

**만들지 않기로 확정한 것**

- P04·P05의 메뉴 영역 (주문 과정에서는 두지 않음)
