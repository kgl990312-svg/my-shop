## 1. 전체 흐름

메인 → (케이스 종류 카드) → 상품 상세 → (꾸미기 시작) → 꾸미기 → (완료) → 확인 → (바로 구매하기) → 주문 정보 → (결제하기) → 주문 완료

- 장바구니 흐름: 확인 → (장바구니 담기) → 장바구니 → (주문하기) → 주문 정보

- 공통 · 네비게이션 바: 로고는 가운데 (누르면 메인) / 메인은 로고 / 상품 상세는 ← 뒤로 + 로고 / 꾸미기는 상단 바(← 뒤로, 도움말, 되돌리기·다시 실행·전체 초기화, 완료) / 확인·장바구니·주문 정보는 ← 뒤로 + 로고, 바 아래에 페이지 제목 / 주문 완료는 로고 (브라우저 뒤로가기는 메인으로) / 꾸미기를 뺀 모든 페이지 오른쪽에 장바구니(담긴 개수 배지)
- 공통 · 나가기 안내창: 꾸민 내용이 있을 때 꾸미기의 ← 뒤로, 확인·주문 정보의 로고나 장바구니를 누르면 "꾸민 내용이 사라져요" (취소 / 나가기) · 꾸미기·확인·주문 정보는 새로고침해도 꾸민 상태 유지
- 공통 · 푸터 (꾸미기 제외): 회사 정보, 고객센터, 이용약관 링크(이용약관 안내창), 개인정보처리방침 링크(개인정보처리방침 안내창)

## 2. 페이지 구성

### 01 메인

- 네비게이션 바: 로고 (가운데)
- 소개 배너: "나만의 쿠션 케이스, 모아에서 완성해요" + 예시 상품 이미지
- 케이스 종류 카드: 목업 이미지 + 이름(크기) + 가격, 가로 배치 (원형, 둥근 정사각형, 하트, 꽃 4개), 클릭하면 상품 상세로 이동
- 직접 꾸민 후기: 제목 + 부제, 후기 카드 8개 가로 넘겨 보기 (이전 / 다음), 카드 = 완성 케이스 사진 + 별점 + 작성자·날짜 + 한 줄 후기 + 케이스 종류, 평균 별점·후기 수와 더보기 없음, 예시 후기

### 02 상품 상세

- 네비게이션 바: ← 뒤로(메인) + 로고(가운데)
- 상품 요약: 큰 목업 이미지, 이름, 크기, 가격, 소재, "꾸민 디자인은 케이스에 인쇄되고, 큐빅은 실제로 붙여 드려요"
- 제작 안내: 단계 5개 (케이스 색 고르기 → 스티커·큐빅·각인으로 꾸미기 → 확인하고 주문하기 → 인쇄·각인하고 큐빅 붙이기 → 배송), 아이콘 + 짧은 이름 (기간은 배송·교환 안내에)
- 탭 3개: 상품정보 / 사이즈 / 배송·교환 안내 (누르면 그 내용으로 스크롤 이동)
- 상품정보: 상세 이미지, 상품 설명
- 사이즈: 크기, 호환 규격 안내 (내 쿠션 확인 방법)
- 배송·교환 안내: 제작·배송 기간, 주문 제작 상품 교환·환불
- "꾸미기 시작" 버튼 (하단 고정): 꾸미기로 이동

### 03 꾸미기

- 상단 바 (헤더·푸터 없음): ← 뒤로(상품 상세), ? 도움말, 되돌리기 · 다시 실행 · 전체 초기화, 완료
- 케이스 캔버스: 바깥 점선 = 케이스, 안쪽 점선 = 꾸밀 수 있는 범위 (뚜껑 윗면만), 확대·축소, 첫 화면 안내
- 선택 상자: 이동, 크기 조절, 회전, 삭제(X)
- 도구 버튼 5개 (오른쪽 세로): 케이스 색 / 큐빅 / 스티커 / 각인 / 케이스 종류(맨 아래), 누르면 화면 아래에 패널이 가로로 열림
- 스티커 공통 규칙: 스티커는 인쇄, 큐빅은 실제로 붙임, 뚜껑 윗면만 꾸밈, 개수 제한 없음 (범위 안), 패널당 6~8개, 모든 종류·색 공통
- 각인: 각인 스타일 클릭 → "각인 입력" 표시 → 입력창에 쓰면 실시간 반영 (10자)
- 완료: 확인으로 이동, 스티커·큐빅·각인이 없으면 비활성화

### 04 확인

- 네비게이션 바: ← 뒤로(꾸미기, 상태 유지) + 로고(가운데) · 바 아래에 페이지 제목 "확인"
- 상품 카드: 왼쪽 꾸민 케이스 이미지(누르면 미리보기 창, 아래에 안내 문구) + 오른쪽 케이스 종류 이름, 선택 요약(케이스 색, 붙인 스티커·큐빅·각인), 가격(케이스 종류별 고정 가격)
- 주문 제작 상품 안내: 인쇄·각인·큐빅 안내, 단순 변심 교환·환불이 어렵다는 안내
- 제작·배송 기간 안내: 주문 제작 기간과 배송 기간
- 하단 고정 바: 총 금액 + "장바구니 담기"(장바구니로 이동) + "바로 구매하기"(주문 정보로 이동)

### 07 장바구니

- 네비게이션 바: ← 뒤로(이전 페이지) + 로고(가운데) · 바 아래에 페이지 제목 "장바구니"
- 담은 케이스 목록: 카드마다 꾸민 케이스 이미지, 케이스 종류 이름, 케이스 색, 붙인 스티커·큐빅·각인, 가격, "다시 꾸미기"(담은 디자인을 복사해 꾸미기로 이동), 삭제 X (수량 없음, 비었을 때 "장바구니가 비었어요")
- 하단 고정 바: 총 금액(담은 케이스 합계) + "주문하기" 버튼 (주문 정보로 이동, 로그인 없이)

### 05 주문 정보

- 네비게이션 바: ← 뒤로(확인 또는 장바구니) + 로고(가운데) · 바 아래에 페이지 제목 "주문 정보"
- 배송 정보: 받는 사람*, 연락처*, 주소*(주소 + 상세 주소), 연락처 형식이 틀리면 오류 문구
- 결제 수단*: 카드 / 간편결제 / 무통장 입금 중 선택
- 동의*: 구매 조건 확인 동의, 개인정보 수집·이용 동의
- 금액: 상품 금액(바로 구매는 케이스 1개, 장바구니 주문은 담은 케이스 합계) + 배송비 = 총 결제 금액
- "결제하기" 버튼: 주문 완료로 이동, 필수 항목을 모두 채워야 활성화

### 06 주문 완료

- 네비게이션 바: 로고(가운데) (뒤로 없음, 브라우저 뒤로가기는 메인으로)
- 완료 영역 (가운데 정렬): 완성 케이스 이미지(체크 자리, 반짝임 효과, 누르면 미리보기 창, 아래에 안내 문구, 여러 개면 첫 번째 + "외 n개") + 완료 문구 + 주문 정보 상자(주문번호, 주문일자, 예상 배송일) + "이미지 저장하기" 버튼
- 주문 요약: 배송지, 결제 수단, 총 결제 금액
- 배송·문의 안내: 제작·배송 기간, 문자 안내(입력한 연락처로 주문 내용 발송), 주문 문의 방법(주문번호 또는 이름과 연락처로 고객센터에 문의)
